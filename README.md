# Boluwatife Adedunmoye — Personal Portfolio & Hub

A sleek, minimalistic, and modern personal website built with **Next.js (App Router)** and **Tailwind CSS**. Designed to serve as a central professional hub that outlines my work across finance, social impact, and design, while providing a seamless way for collaborators, founders, and peers to get in touch.

Live Link: *(Once deployed, paste your Vercel URL here)*

---

## 🛠️ Tech Stack & Features

- **Framework:** Next.js 14+ (App Router)
- **Styling:** Tailwind CSS (Clean slate UI, responsive grid system)
- **Icons:** Lucide React
- **Forms & Mail:** Web3Forms (Zero-backend contact form configuration)
- **Hosting:** Optimised for Vercel
